# Análisis de Ventas por Región - Power BI

## ¿Qué problema resolví?
Analicé los datos de ventas de una empresa para entender qué regiones generan más ingresos y cuáles necesitan atención.

## ¿Qué hice?
1. Cargué y revisé los datos de ventas (fecha, región, producto, categoría, vendedor, cantidad, precio, descuento, ingresos).
2. Creé un dashboard en Power BI que muestra la suma de ingresos por región.

## ¿Qué encontré?
- **North** es la región con más ingresos totales.
- **Central** y **South** le siguen de cerca.
- **West** y **East** tienen los ingresos más bajos.

## ¿Qué recomendaría?
- Investigar por qué West y East venden menos: ¿es el precio, el producto o el vendedor?
- Considerar campañas de marketing específicas para esas regiones.

## Herramientas usadas
- Power BI
- Datos de ventas en CSV
